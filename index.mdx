Discord Rawrbot is a community Discord bot built with [discord.py](https://discordpy.readthedocs.io/), providing slash commands for moderation, music link sharing, text translation, and general server utilities. It supports user-install mode, meaning many commands work in DMs and group chats — not just inside servers.

## Getting Started

<Steps>
  <Step title="Add to Your Server">
    Use the [invite link](https://discord.com/oauth2/authorize?client_id=1118629362368008283&permissions=2147486720&scope=bot&permissions=2147486720&scope=messages.read%20bot) to add Rawrbot to your Discord server.
  </Step>
  <Step title="Self-Host (Optional)">
    Clone the repository, install dependencies, and create your `config.json` with a bot token to run your own instance.
  </Step>
  <Step title="Explore Commands">
    Browse the [Command Reference](/commands/general) to see every available slash command with parameters and usage examples.
  </Step>
</Steps>

<Note>
  Rawrbot uses Discord slash commands (`/command`). Make sure your Discord client is up to date to access the command picker.
</Note>
